# 组员 1 AI/NLP D1–D5

**目标**：让真实 Qwen 返回受约束的 `ExperimentConfig`，并启动可核查的知识库。对应 AV-001、AV-004、AV-002；对接组员 3。仓库的 `backend/app/ai/` 当前为空，`/experiments/parse` 仍返回 501。

| 日 | 当天要做的事 | 当天交付与检查 |
|---|---|---|
| D1 | 阅读 `schemas/models.py`、`api-contracts.md`；向组员 3 确认 Qwen 兼容 API 地址、模型名、凭据取得方式，不把 Key 写入仓库。 | 10 条自然语言配置样例，覆盖排序名、规模、分布、seed、显式数组和非法要求。 |
| D2 | 写 `ai/provider.py`：HTTP 调用、明确超时、非 2xx、无效 JSON 处理；记录模型名与耗时，不记录 Key。 | 用真实凭据跑最小请求，保留脱敏响应和失败样例；离线 Mock 单独标记。 |
| D3 | 写解析提示词与 `ai/planner.py`，只允许模型输出 JSON；用 Pydantic 校验，未知字段拒绝，失败最多修复一次。与 3 接通 parse→run。 | 从一句话到冒泡实测结果的 HTTP 往返；10 条样例给出逐条通过/失败记录。 |

| D5 | 建 BGE Embedding 与 FAISS 离线索引脚本，固定模型名、向量维度和知识版本；先验证检索 Top-k。 | 给 3 的检索函数输入/输出样例；无结果时返回空来源及明确提示。 |
