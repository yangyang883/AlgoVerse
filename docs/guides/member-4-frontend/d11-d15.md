# 组员 4 前端 D11–D15

**目标**：D12 完成报告网页预览和研究评价页，并冻结 P0 UI；D13–D15 修稳定性。对应 AV-009～AV-012。

| 日 | 工作 | 交付与验收 |
|---|---|---|
| D11 | 接报告 API，展示配置、输入/输出、实测指标、校验、AI 解释与限制；实现浏览器打印样式。 | 页面/打印预览与同一 run_id 数据一致，长轨迹不把报告撑坏。 |
| D12 | 建研究评价页，只读展示 5 提供的 A/B/C/D 汇总、失败例和实际样本量；与全组冻结 P0 UI。 | 场景 A/B/C 固定操作脚本可连续复演；前端 build 通过。 |
