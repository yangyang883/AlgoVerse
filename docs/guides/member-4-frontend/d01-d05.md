**目标**：把现有 D1 页面发展为可确认配置、显示真实轨迹的工作台。对应 AV-009；只消费 `frontend/src/types/contracts.ts` 生成类型。

| 日 | 工作 | 交付与验收 |
|---|---|---|
| D1 | 阅读 `App.vue`、`api-contracts.md`；在联网开发机运行 `npm install`、`npm run build`，生成并提交 lockfile。 | Vue 页面和后端健康检查在正常 Windows 终端实际打开；记录 Node/npm 版本。 |
