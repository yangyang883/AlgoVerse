# 组员 2 算法 D11–D15

**目标**：D12 冻结执行器 P0 行为；D13–D15 配合评测与稳定性测试。对应 AV-005、AV-007、AV-010、AV-012。

| 日 | 工作 | 交付与验收 |
|---|---|---|
| D11 | 复演项目书场景 A：有序数组首枢轴快排最坏情况、不同策略对照；检查验证器和统计与原始输出一致。 | 保存输入数组、策略、版本、比较/递归指标与 run_id。 |
| D12 | 冻结四排序参数、轨迹协议和计数规则；给 3/4/5 最终样例。 | 四排序回归全绿，算法能力表与实际实现一致。D12 后不加新算法。 |
| D13 | 测 n=0、1、40、41、2000 及恶意边界输入；检查关闭动画后内存与响应体。 | 不超资源上限；错误为清晰的 4xx 而非进程崩溃。 |
| D14 | 配合 5 跑执行与性能解释题、反例题；提供原始执行结果作为评分真值。 | 每题可由配置与 seed 重放，不使用 LLM 指标。 |
| D15 | 修复计数、轨迹或验证缺陷；重跑同一组回归，不改既定样例以美化成绩。 | 缺陷记录含最小复现、修复提交与前后对照。 |

**闸门**：快排递归深度可能触及 Python 限制，需明确保护或改迭代实现。性能对比只可说明当前机器、当前实现上的观察，不把毫秒数推成复杂度证明。若 D12 未过，取消全部 P1 并优先保证四排序真实闭环。
