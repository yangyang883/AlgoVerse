# 组员 5 科研评测与交付 D11–D15

**目标**：D12 固定演示和 P0 功能范围，D13–D15 冻结题集并生成真实基线/消融结果。对应 AV-012、AV-013。

| 日 | 工作 | 交付与验收 |
|---|---|---|
| D11 | 与 1/2/3/4 复演 A/B/C，核对每个结论的来源、配置、run_id、校验与图表。 | 两套必须真实运行的实验脚本及一套知识边界演示脚本。 |
| D12 | 参加 P0 功能冻结；确认报告预览、工具编排、反例和对比是否完成。 | 闸门清单逐项写通过/失败/未测，缺口进入缺陷队列。 |
| D13 | 冻结题集版本和人工评分规范；目标 100 题，未凑齐则记录实际数量与覆盖率。 | 题集不可因结果难看而修改；每题有唯一 ID 和标准答案/预期字段。 |
| D14 | 跑 A/B/C/D 基线；保存逐题原始结果、模型参数、提示词/知识版本、执行环境。 | 评测脚本从空目录可复现报告；失败题保留。 |
| D15 | 做至少一项消融（如去掉 RAG 或去掉 Schema 校验），同一题集重跑并分类错误。 | 统计方法、分母、未完成题、人工复核人与局限均记录。 |

**统计规则**：知识问答需人工核对来源与事实；配置题算字段级准确率和合法率；执行题用真实验证器和数据一致性；异常题检查是否拒绝且提示可理解。不能用模型自评替代人工真值，也不能预写准确率。
