# 组员 5 科研评测与交付 D16–D20

**目标**：交付可复现评测、课程报告、PPT 与现场演示。对应 AV-012、AV-013。

| 日 | 工作 | 交付与验收 |
|---|---|---|
| D16 | 汇总基线与至少一项消融的原始 CSV/JSON、图表、失败分类和人工复核记录。 | 结论只引用实际分子/分母与运行环境；负结果照实保留。 |
| D17 | 写课程报告：问题、系统架构、NLP 方法、算法可信执行、数据集、指标、结果、误差与限制。 | 每张表可追到评测脚本和版本，不抄占位数字。 |
| D18 | 做 PPT 和答辩操作单，分配五人讲解：NLP、算法、后端、前端、科研结论。 | 场景 A/B/C 的每一步输入、预计画面、失败预案和负责人口径一致。 |
| D19 | 在目标机器完整彩排并计时；随机抽题验证不是只会跑固定截图。 | 记录故障、修复和再次复演结果；离线案例醒目标注。 |
| D20 | 封存题集、原始结果、报告、PPT、演示脚本和最终提交哈希；核对 GitHub README。 | 另一名组员按文档可重跑核心评测；答辩中明确 P0/P1/P2 完成边界。 |

**失败预案**：若 D16 评测尚未完整，停止一切 P1，保住一组真实基线、一项真实消融和失败分析，并明确样本覆盖不足。报告不承诺“100% 正确”或虚构性能提升。
