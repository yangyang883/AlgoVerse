# 二十天路线图

| 阶段 | 五人任务（1/2/3/4/5） | 交付与依赖 | 测试门槛 | 阻塞与降级 |
|---|---|---|---|---|
| D1–D3 | 1 Provider 与解析样例；2 冒泡/验证；3 契约/API/SQLite 设计；4 最小工作台；5 测试格式 | Qwen→配置→校验→真实执行→JSON；依赖模型凭据和统一 Schema | 固定自然语言样例及接口 E2E | 模型不可达则手动配置演示，标注模型链路未通过；停止 UI 增强 |
| D4–D7 | 1 RAG/上下文；2 另三排序；3 编排与保存；4 SVG 播放器/聊天；5 测试脚本 | 四排序、来源提示、追问、动画；依赖轨迹协议 | 四排序边界测试、10 个解析样例、追问修改 | 未通过则禁止 P1，集中修契约及最小播放器 |
| D8–D12 | 1 解释/一次修复；2 快排反例/策略；3 工具白名单与对比/报告 API；4 对比图/报告预览；5 固定演示 | 可复现的反例与同输入比较；依赖存储/日志 | 两套真实演示和结果验证 | 去掉 P1 并于 D12 冻结 P0 新功能 |
| D13–D16 | 1 整理模型配置；2 边界/负载；3 系统故障处理；4 UI 稳定性；5 冻结 100 题目标、A/B/C/D 和消融 | 原始结果、错误分类；依赖稳定接口 | 评测重跑产物一致、关键失败记录 | 停新功能，至少保留一组基线与一项消融 |
| D17–D20 | 1 离线预案；2 真实算法证据；3 目标机器部署；4 演示 UI；5 报告/PPT/演练 | 一键启动文档和答辩材料 | 目标机器复演 A/B/C | 只修关键故障，离线案例必须标记 |

D3、D7、D12、D16、D20 为硬验收。D7 未完成 P0 则不得启动 P1；D12 冻结 P0 新功能。
