# EvidenceLab 设计与评测

EvidenceLab 将结构化假设转成可执行计划，调用现有白名单算法，保存每次运行并依据实际输出生成证据报告。它解决算法解释缺少可复现实验依据的问题。现阶段计划由调用方结构化提交，不提供真实自然语言自动规划；组员 1 的 Qwen 后续可提供候选意图，但计划验证、执行、指标采集和结论约束仍由确定性程序完成。

计划支持两类实验：`distribution_effect` 固定算法和规模，改变有序、逆序、随机分布；`same_input_comparison` 要求显式且完全一致的数组与指标列表。当前仅注册冒泡排序，快速排序等未注册算法直接拒绝。分布实验不属于同输入公平对照。每个 run_id 可经原有实验 API 读取配置、输入、输出、指标、验证状态、版本、环境和时间。报告保存 run_id、输入 SHA-256 指纹、原始指标、验证结果和限制，因此结论可以反查。

执行失败、输出验证失败或证据缺失时，报告使用“证据不足”；单次小规模观测不能证明渐近复杂度。运行时间仅代表当前环境。后续评测由组员 5 使用标注的合法与非法计划测规划正确率，以成功持久化且验证通过的计划测执行成功率，以报告指标逐项等于 run_id 原始指标测证据一致性。对照实验固定输入比较已注册算法或策略；消融实验可分别关闭计划约束或证据校验，统计非法计划通过率和错误结论率。本文不预设任何准确率或效果提升。

API：`POST /api/v1/evidence/plans` 创建计划，`POST /api/v1/evidence/plans/{plan_id}/run` 执行，`GET /api/v1/evidence/reports/{evidence_id}` 查询报告。均使用现有 APIResponse 和 request_id。

本模块为独立 P1 扩展，不计入尚未通过的 D7/P0 验收。
